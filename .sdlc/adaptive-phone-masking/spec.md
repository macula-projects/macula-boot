# Spec: 手机与座机自适应脱敏 (from intent.md 2026-11-18)
Status: accepted

## Source intent
[已验收需求](intent.md)：同步增强手机、座机方法，handlerPhone 识别类型后委派调用；保留全球国际码、座机区号及分机，覆盖短号。

## Requirements
1. 保留 handlerMobile、handlerFixedPhone、handlerPhone 的名称及签名，null 和空串仍返回 null。handlerPhone 仅识别和委派，掩码逻辑由专用方法及共享私有辅助方法完成。
2. 手机支持全球国家呼叫码的 `+` 和 `00` 形式，国际码不参与本地号码长度计算；无国际码时默认按中国大陆号码解释，不猜测外国本地号码所属国家。
3. 手机本地号码 8 位及以上保留前三位和后四位，中间数字逐位替换星号，如 `+86 13812340000 → +86 138****0000`、`008613812340000 → 0086138****0000`。
4. 座机保留可识别的国际码、区号及分机号；主号 8 位及以上保留后四位，其余数字逐位隐藏：`010-87651234-888 → 010-****1234-888`。
5. 去除国际码、座机区号及分机后，两个专用方法都对 4～7 位号码隐藏中间两位，起始下标为 `(长度-2)/2`（向下取整）；1～3 位全部隐藏。例如 `1234567 → 12**567`、`1234 → 1**4`、`123 → ***`。
6. 保留可识别输入中的原国际码写法、空格、括号和连字符，只替换选中的数字，不把输出重新格式化为另一个拨号格式。
7. 分机识别支持明确的 `ext`、`ext.`、`x`、`#`、`转`、`分机` 标记及国内 `区号-7或8位主号-分机` 形式；分机和其分隔符原样保留。不将国际号码普通分组连字符误作分机。
8. 不因号码无法通过完整有效性校验而跳过脱敏；短号仍执行长度规则。无法确定手机或座机的号码委派到 handlerFixedPhone，使用保守的座机主号规则；无法识别区号时不擅自保留疑似区号。未知国际码或无法安全划分的异常格式返回单个 `*`，不直接返回原始数字。

## Non-goals
不修改姓名、证件、邮箱等规则，不改注解名称或序列化映射，不联网查询号码、不校验真实归属或可接通性，不提供外国无国际码号码的自动地域猜测，不调整配置加解密工具。

## Design
- Web Starter 引入 Java 8 兼容的 Google libphonenumber 依赖，复用其国家呼叫码、号码类型及可识别地理区号元数据；依赖版本在实施计划中固定，不手写全球国家码表。
- 解析原输入，建立数字在原字符串中的位置映射，提取明确的分机及国际码；`00` 仅在解析视图中转换为 `+`，输出保留原表示。
- 无国际码时默认 CN；对完整号码复用元数据识别类型/区号。国内显式区号加短主号的形式额外保留可识别区号，防止短主号被当作无效号码而不脱敏。
- handlerMobile 只保留国际码，不从本地手机号剥离区号；handlerFixedPhone 剥离可识别区号后处理主号，两者调用同一长度掩码辅助逻辑。handlerPhone 确认为 MOBILE 时调用手机方法，其余类型（含 FIXED_LINE_OR_MOBILE 和 UNKNOWN）调用座机方法，兼容无法明确区分的国家号码计划。
- 通过原位置映射替换数字，保留国际码、区号、分机和格式字符；所有状态限于单次调用，无全局可变解析状态。

## Data and interfaces
三个公开方法签名及对应 MOBILE、FIXED_PHONE、PHONE 序列化调用保持不变，行为按上述规则增强；新增依赖，无数据库、网络服务或配置项变更。

## Flagged concerns
- 国际分类歧义：部分国家号码无法可靠区分手机和座机；FIXED_LINE_OR_MOBILE 采用座机规则，保留可识别区号并减少展示位数，non-blocking。
- 缺少地域信息：无国际码的外国本地号码存在固有歧义；默认 CN，外国号码需显式国际码，non-blocking。
- 不规则输入：未知国家码及无法可靠划分的内容使用 `*` 回退；不会以原文返回，non-blocking。
- 新依赖：全球规则由 libphonenumber 离线元数据支持，增加 Web Starter 依赖，实施时固定兼容版本并测试，non-blocking。
- 已有工作与策略：保留当前其他修改；未发现额外 AGENTS.md、CLAUDE.md、REVIEW.md 或组织策略，遵循当前 SDLC 人工验收规则，non-blocking。

## Verification strategy
- 参数化测试覆盖三个方法：无国际码、+86/0086、+1、+44、+852 等国家码，手机、座机、分类歧义、国内三/四位区号、无区号主号、分机及格式字符。
- 验证主号每个长度边界 1～8、11 位，奇偶短号、国际码/区号/分机不参与长度计算，首尾位正确且至少按规则隐藏。
- 验证显式分机标记、国内连字符分机，国际普通分组不误认分机；非法输入保守回退，未知码不泄漏。
- 对可明确分类的号码断言 handlerPhone 与对应专用方法输出一致；验证 MOBILE/FIXED_PHONE/PHONE 的真实序列化路径；回归已有姓名及其他脱敏测试。
- Java 8 编译、目标 Web/Commons 测试及全仓测试，记录真实结果和外部服务限制；执行 git diff --check。
