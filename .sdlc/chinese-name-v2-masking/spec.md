# Spec: 中文名 V2 脱敏规则优化 (from intent.md 2026-11-18)
Status: accepted

## Source intent
[已验收需求](intent.md)，验收提交：`4af1830b`。

## Requirements
1. 两字姓名仅保留末字：`张三 → *三`。
2. 三字及以上姓名保留整体首尾字：`张三丰 → 张*丰`，`欧阳娜娜 → 欧*娜`。
3. `·`、`•`、`・`、`.`、`．` 保留原位且不计入字数；带点姓名按整体首尾处理：`阿不都·热合曼 → 阿*·*曼`。
4. 单字姓名保持原样；null 和空字符串仍返回 null；仅含间隔点时保持原样。
5. 按 Unicode 码点处理字符，生僻汉字不被拆开，每段连续被隐藏的字替换为一个星号；保留间隔点，间隔点两侧分别压缩星号。
6. 按 `/` 分隔姓名，各段独立计算姓名字数及首尾，保留所有斜杠和空段，例如 `张三/欧阳娜娜 → *三/欧*娜`，`/张三//李四/ → /*三//*四/`。

## Non-goals
不更改 V1、其他脱敏规则、注解或序列化映射，不引入依赖。

## Design
只调整 `SensitiveUtil.handlerUsernameV2` 及其私有辅助方法。先按 `/` 分段（保留空段），每段独立统计非间隔点字符数；遍历保留间隔点和允许展示的首尾字符，每段连续隐藏区域只输出一次 `ASTERISK_CHAR`，遇到间隔点重置隐藏状态，最终按原斜杠顺序拼接。

## Data and interfaces
方法签名保持不变，无数据库或配置变更。

## Flagged concerns
- 字符范围：除明确列出的五种点字符外，其他字符均参与姓名计数；不扩展为姓名格式校验，non-blocking。
- 既有工作：相关源码已有用户未提交修改，实施时保留并在其基础上调整，non-blocking。
- 项目策略：未发现仓库内 AGENTS.md、CLAUDE.md、REVIEW.md 或额外组织策略；遵循当前会话的 SDLC 人工验收规则，non-blocking。

## Verification strategy
更新旧逐字星号断言，新增连续隐藏压缩、间隔点两侧单星、斜杠分段、首尾及连续斜杠、空段、分段单字、多段带点姓名测试；继续覆盖 null、空串、单字、两字、多字、五种间隔点、仅含点及 Unicode 扩展汉字；检查修改范围并运行 `git diff --check`。

## Revision
用户明确新增单星和斜杠分段要求；本稿更新设计，用户已明确确认，不将旧版 25 个用例通过记录用于新版。

用户明确确认：单字保持原样，两字只保留末字，三字及以上保留首尾；其余间隔点、单星、斜杠分段及 Unicode 规则保持原样。
